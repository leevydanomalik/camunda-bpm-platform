# Phase 0b — Plugin contract finish + 28-slot catalog + build-time registry — implementation plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete the v1 plugin contract for `webapps-next/`: extend the manifest schema with the optional metadata the spec defines (`priority`, `pollIntervalMs`, `requiredGroups`, optional `server` entry), lock in the 28 slot ids that legacy AngularJS plugins targeted, replace the hand-maintained registry with a build-time codegen step that scans `plugins/*/plugin.json`, and ship a second reference plugin (with a server entry) so future plugins have two patterns to copy.

**Architecture:** The v0 work (already shipped: `src/lib/plugins/{types,registry,extension-slot}.tsx`, one sample plugin) gets two upgrades: (a) the manifest type grows the spec-defined optional fields; (b) `registry.ts` becomes auto-generated by a `scripts/build-plugin-registry.mjs` step that runs as a `prebuild` npm script. The 28-slot catalog lives at `src/lib/plugins/slots.ts` as a `const`-asserted array — anywhere `point: string` is read, callers can constrain to that union for type safety. Server entries become Next route handlers under `/api/plugin/<id>/<method>` discovered at build time by the same generator.

**Tech Stack:** TypeScript, Next.js 16 (App Router, Turbopack), Node.js (Node 20+) for the codegen script, Zod for schema validation, Playwright for e2e.

**Source spec:** `webapps-next/docs/superpowers/specs/2026-05-21-webapps-migration-roadmap-design.md` — §3.3 plugin contract, §5 slot catalog, §7 Phase 0 deliverables.

import { z } from "zod";

import { SLOT_IDS } from "./slots";

const SlotIdSchema = z.enum(SLOT_IDS);

const ExtensionPointSchema = z.object({
  point: SlotIdSchema,
  exportName: z.string().min(1),
  priority: z.number().int().optional(),
  label: z.union([z.string(), z.record(z.string(), z.string())]).optional(),
});

const ServerSchema = z
  .object({
    entry: z.string().min(1),
  })
  .strict();

export const ManifestSchema = z
  .object({
    apiVersion: z.literal("1"),
    id: z.string().regex(/^[a-z0-9-]+$/, "id must be kebab-case ascii"),
    version: z.string(),
    displayName: z.string(),
    description: z.string().optional(),
    app: z.enum(["cockpit", "tasklist", "admin", "welcome", "shared"]),
    client: z.object({
      extensionPoints: z.array(ExtensionPointSchema).min(1),
    }),
    server: ServerSchema.optional(),
    pollIntervalMs: z.number().int().positive().optional(),
    requiredGroups: z.array(z.string()).optional(),
  })
  .passthrough(); // forward-compat: unknown top-level keys are ignored, not rejected.

export type Manifest = z.infer<typeof ManifestSchema>;
```

### Task 3: Build-time registry generator

**Files:**

- [ ] **Step 1: Create the script**

```js
#!/usr/bin/env node
// Discovers webapps-next/plugins/*/plugin.json, validates with Zod, emits
// src/lib/plugins/registry.generated.ts. Run as a prebuild step.

import { readdirSync, readFileSync, statSync, writeFileSync } from "node:fs";
import { dirname, join, relative } from "node:path";
import { fileURLToPath } from "node:url";

import { ManifestSchema } from "../src/lib/plugins/manifest-schema.ts";

const ROOT = dirname(fileURLToPath(import.meta.url)) + "/..";
const PLUGIN_DIR = join(ROOT, "plugins");
const OUT = join(ROOT, "src/lib/plugins/registry.generated.ts");

function discover() {
  if (!statSync(PLUGIN_DIR, { throwIfNoEntry: false })) {
    console.log(`No plugins/ directory — emitting empty registry.`);
    return [];
  }
  const entries = readdirSync(PLUGIN_DIR);
  const manifests = [];
  for (const id of entries) {
    const dir = join(PLUGIN_DIR, id);
    if (!statSync(dir).isDirectory()) continue;
    const manifestPath = join(dir, "plugin.json");
    let raw;
    try {
      raw = JSON.parse(readFileSync(manifestPath, "utf8"));
    } catch (e) {
      console.error(`[plugins] ${id}: missing or invalid plugin.json — skipping`);
      continue;
    }
    const parsed = ManifestSchema.safeParse(raw);
    if (!parsed.success) {
      console.error(`[plugins] ${id}: schema error:\n${parsed.error.message}`);
      process.exit(1);
    }
    manifests.push({ id, dir, manifest: parsed.data });
  }
  return manifests;
}

function emit(manifests) {
  // Sort by id so the generated file is stable across runs.
  manifests.sort((a, b) => a.id.localeCompare(b.id));
  const lines = [
    "// AUTO-GENERATED by scripts/build-plugin-registry.mjs — do not edit by hand.",
    "// Regenerate via `npm run build` (prebuild script) or `node scripts/build-plugin-registry.mjs`.",
    "",
    'import type { PluginManifest, RegisteredPlugin } from "./types";',
    "",
  ];

  for (const { id, manifest } of manifests) {
    const clientRel = relative(dirname(OUT), join(PLUGIN_DIR, id, "client")).replace(/\\/g, "/");
    lines.push(`import * as client_${safeIdent(id)} from "${clientRel}";`);
    lines.push(`import manifest_${safeIdent(id)} from "${relative(dirname(OUT), join(PLUGIN_DIR, id, "plugin.json")).replace(/\\/g, "/")}";`);
    if (manifest.server) {
      const serverRel = relative(dirname(OUT), join(PLUGIN_DIR, id, manifest.server.entry.replace(/\.[cm]?[jt]sx?$/, ""))).replace(/\\/g, "/");
      lines.push(`import * as server_${safeIdent(id)} from "${serverRel}";`);
    }
  }
  lines.push("");
  lines.push("export const PLUGINS: RegisteredPlugin[] = [");
  for (const { id, manifest } of manifests) {
    lines.push(`  {`);
    lines.push(`    manifest: manifest_${safeIdent(id)} as PluginManifest,`);
    lines.push(`    clientExports: client_${safeIdent(id)} as RegisteredPlugin["clientExports"],`);
    if (manifest.server) {
      lines.push(`    serverHandlers: server_${safeIdent(id)} as RegisteredPlugin["serverHandlers"],`);
    }
    lines.push(`  },`);
  }
  lines.push(`];`);
  lines.push("");

  writeFileSync(OUT, lines.join("\n"), "utf8");
  console.log(`[plugins] wrote ${OUT} with ${manifests.length} plugin(s).`);
}

function safeIdent(id) {
  return id.replace(/[^a-zA-Z0-9_]/g, "_");
}

emit(discover());
```

// Thin shim over registry.generated.ts (built by scripts/build-plugin-registry.mjs).
// Anything that *queries* the registry — slot dispatch, server handler lookup —
// lives here.

import type { RegisteredPlugin } from "./types";
import type { SlotId } from "./slots";

import { PLUGINS } from "./registry.generated";

export { PLUGINS } from "./registry.generated";

export function pluginsForPoint(point: SlotId): Array<{
  plugin: RegisteredPlugin;
  extension: RegisteredPlugin["manifest"]["client"]["extensionPoints"][number];
}> {
  const matches: Array<{
    plugin: RegisteredPlugin;
    extension: RegisteredPlugin["manifest"]["client"]["extensionPoints"][number];
  }> = [];
  for (const plugin of PLUGINS) {
    for (const ext of plugin.manifest.client.extensionPoints) {
      if (ext.point === point) matches.push({ plugin, extension: ext });
    }
  }
  matches.sort((a, b) => (b.extension.priority ?? 0) - (a.extension.priority ?? 0));
  return matches;
}

export function pluginById(id: string): RegisteredPlugin | undefined {
  return PLUGINS.find((p) => p.manifest.id === id);
}

```ts
import { NextResponse } from "next/server";

import { getSession } from "@/lib/auth/session";
import { pluginById } from "@/lib/plugins/registry";

async function dispatch(req: Request, params: Promise<{ id: string; method: string }>) {
  const { id, method } = await params;
  const plugin = pluginById(id);
  if (!plugin) return NextResponse.json({ error: "Unknown plugin" }, { status: 404 });

  // Group-based access gate, if declared.
  if (plugin.manifest.requiredGroups?.length) {
    const session = await getSession();
    if (!session) return NextResponse.json({ error: "Not authenticated" }, { status: 401 });
    const intersect = plugin.manifest.requiredGroups.some((g) => session.groups.includes(g));
    if (!intersect) return NextResponse.json({ error: "Forbidden" }, { status: 403 });
  }

  const handler = plugin.serverHandlers?.[method];
  if (!handler) return NextResponse.json({ error: "Unknown method" }, { status: 404 });

  return handler(req);
}

export async function GET(req: Request, ctx: { params: Promise<{ id: string; method: string }> }) {
  return dispatch(req, ctx.params);
}
export async function POST(req: Request, ctx: { params: Promise<{ id: string; method: string }> }) {
  return dispatch(req, ctx.params);
}
```

import { engineGet } from "@/lib/camunda/engine";

type DefStats = { id: string; key: string; instances: number };

export async function counts(_req: Request): Promise<Response> {
  try {
    const stats = await engineGet<Array<{ id: string; key: string; instances: number }>>(
      "/process-definition/statistics?running=true",
    );
    const top = stats
      .map<DefStats>((s) => ({ id: s.id, key: s.key, instances: s.instances }))
      .sort((a, b) => b.instances - a.instances)
      .slice(0, 5);
    return Response.json({ top });
  } catch (e) {
    return Response.json({ error: "Engine unreachable" }, { status: 502 });
  }
}
```

# Plugin samples

Two reference plugins for the v1 contract:

- `sample-dashboard-widget/` — client-only; renders into `cockpit.dashboard.widget`.
- `process-metrics-server-plugin/` — client + server entry; demonstrates the `/api/plugin/[id]/[method]` route handler dispatch.

## Manifest

Every plugin lives at `webapps-next/plugins/<id>/plugin.json`:

```json
{
  "apiVersion": "1",
  "id": "your-plugin-id",
  "version": "0.1.0",
  "displayName": "Your Plugin",
  "app": "cockpit | tasklist | admin | welcome | shared",
  "client": {
    "extensionPoints": [
      { "point": "<slot-id>", "exportName": "YourComponent", "priority": 0 }
    ]
  },
  "server": { "entry": "./server.ts" },
  "pollIntervalMs": 30000,
  "requiredGroups": ["camunda-admin"]
}
```

The 28 valid slot ids are listed in `webapps-next/src/lib/plugins/slots.ts` (`SLOT_IDS`).

## Client entry

`webapps-next/plugins/<id>/client/index.tsx` exports React components. The names must match `exportName` in the manifest.

## Server entry (optional)

`webapps-next/plugins/<id>/server.ts` exports `(req: Request) => Promise<Response>` functions. They are mounted as Next route handlers at `/api/plugin/<id>/<exported-name>`.

## Build-time registry

`scripts/build-plugin-registry.mjs` scans `plugins/*/plugin.json` and emits `src/lib/plugins/registry.generated.ts`. Runs automatically as `prebuild`. Manual regen: `npm run build:plugins`.

## Authoring a third-party plugin

1. Drop your plugin dir under `webapps-next/plugins/`.
2. Validate the manifest against `src/lib/plugins/manifest-schema.ts` (Zod) — `npm run build:plugins` will reject malformed manifests with an error.
3. The plugin's components automatically appear in the slot.
4. Server-side endpoints are auto-mounted; no Next route handlers to write.

## What's NOT supported in v1

- Hot-load at runtime — plugins are bundled at build time. Add a plugin → rebuild.
- Slot overrides (replacing a default tab rather than appending to it) — appended-only model.
- Native dependencies — plugins ship code only; rely on host's `node_modules`.

### Task 9: E2E spec — plugin loading + slot dispatch + server entry

**Files:**
- Create: `webapps-next/e2e/plugins.spec.ts`

- [ ] **Step 1: Create the spec**

```ts
import { expect } from "@playwright/test";

import { loginAs, test } from "./_fixtures";

test.describe("plugins @phase-0", () => {
  test("dashboard widget plugins render into cockpit.dashboard.widget", async ({ page, request }) => {
    await loginAs(request);
    await page.context().addCookies(
      (await request.storageState()).cookies.map((c) => ({
        ...c,
        url: "http://localhost:3000",
      })),
    );
    await page.goto("/cockpit");
    // Both bundled plugins target this slot.
    await expect(page.getByText("Recent deployments")).toBeVisible();
    await expect(page.getByText("Top running processes")).toBeVisible();
  });

  test("server-entry plugin endpoint responds", async ({ request }) => {
    await loginAs(request);
    const res = await request.get("/api/plugin/process-metrics-server-plugin/counts");
    expect(res.status()).toBeLessThan(500);
    const body = await res.json();
    expect(body).toHaveProperty(/^(top|error)$/);
  });

  test("unknown plugin id returns 404", async ({ request }) => {
    await loginAs(request);
    const res = await request.get("/api/plugin/no-such-plugin/anything");
    expect(res.status()).toBe(404);
  });
});
```
